# Velsis

Aplicação de gerenciamento de usuários, com API Spring Boot e frontend Angular.

## Pré-requisitos

- Java 17
- PostgreSQL
- Node.js e npm

## Banco de dados

A configuração atual da API conecta ao PostgreSQL em `localhost:5432`, no banco `postgres`. Ajuste `src/main/resources/application.yaml` se sua configuração for diferente.

O Hibernate está configurado com `ddl-auto: validate`, então a tabela precisa existir antes de iniciar a API. Execute este script no banco `postgres`:

```sql
CREATE SCHEMA IF NOT EXISTS velsis;

CREATE TABLE velsis.users (
   id int8 GENERATED BY DEFAULT AS IDENTITY (
      INCREMENT BY 1
      MINVALUE 1
      MAXVALUE 9223372036854775807
      START 1
      CACHE 1
      NO CYCLE
   ) NOT NULL,
   "name" varchar NOT NULL,
   birth_date date NULL,
   "document" varchar NULL,
   address_line varchar NULL,
   address_number int4 NULL,
   city varchar NULL,
   state varchar NULL,
   zip varchar NULL,
   created_at timestamptz NOT NULL,
   updated_at timestamptz NOT NULL,
   CONSTRAINT users_pk PRIMARY KEY (id)
);
```

## Iniciar a aplicação

1. Inicie o PostgreSQL.
2. Na pasta `velsis-api`, inicie a API:

   ```bash
   ./mvnw spring-boot:run
   ```

   No Windows, use `mvnw.cmd spring-boot:run`. A API ficará disponível em `http://localhost:8080`.

3. Em outro terminal, entre na pasta `frontend-velsis`, instale as dependências e inicie o Angular:

   ```bash
   cd ../frontend-velsis
   npm install
   npm start
   ```

   Abra `http://localhost:4200` no navegador.

O frontend consome a API em `http://localhost:8080`.
